# Growth ERP 체험·촬영 안내

모든 데이터는 가상입니다. 브라우저를 넓은 PC 화면으로 열고 상단 **초기화**를 누르면 같은 구성에서 다시 시작합니다. 날짜와 식별자는 초기화 시점에 따라 달라집니다.

| 순서 | 체험·촬영할 장면 | 확인할 변화 |
| --- | --- | --- |
| 1 | 개요 대시보드 | 6개월 매출 추이, 미수금, 진행 중인 프로젝트 |
| 2 | 루미나 캠퍼스 거래처 상세 | 견적·주문·수금 이력이 같은 거래처로 연결 |
| 3 | 투어의 제안 중인 견적 | 품목·수량·단가·내부 마진과 견적 버전 |
| 4 | 견적 PDF·XLSX 생성 | 가상 공급자 정보, 고객용 문서에서 내부 원가 제외 |
| 5 | 견적을 주문으로 전환 | 견적 원본 보존, 주문에 품목과 금액 복사 |
| 6 | 투어의 부분 납품 주문 | 청구 금액, 실제 납품 수량, 결제 잔액의 구분 |
| 7 | 투어의 미수금 거래에서 수금 기록 | 결제 연결, 잔액과 자동 할 일 갱신 |
| 8 | 품목·재고 및 매출 분석 | 입출고 기반 재고, 실제 공급 기준 손익 |
| 9 | 모바일 할 일·거래처 | 조회와 간단한 업무 관리에 집중한 별도 화면 |

영상은 **개요 → 견적 → 주문 → 납품 → 수금 → 변경된 개요** 순서로 구성하면 2~3분 안에 연결된 업무를 보여줄 수 있습니다. 화면 오른쪽 위 가이드 검색에서 업무 개념과 따라 해보기 문서를 확인할 수 있습니다. 생성형 AI 응답처럼 소개하지 않습니다.
