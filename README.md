# Growth ERP · Business in Focus

**견적부터 납품, 수금까지. 작은 비즈니스의 업무를 하나의 흐름으로 연결합니다.**

실제 운영용으로 개발한 ERP·CRM의 시스템을 기반으로 만든 인터랙티브 포트폴리오입니다. 모든 회사, 인물, 연락처, 품목 단가, 거래와 문서는 가상입니다. 운영 데이터, 회사 도장, 실제 견적 파일, 운영 환경 변수, 기존 Git 이력은 포함하지 않습니다.

[Live demo](https://growth-erp-portfolio.vercel.app) · [Quick Look 소개](docs/QUICK_LOOK.md) · [체험 시나리오](docs/DEMO.md) · [구조와 설계](docs/ARCHITECTURE.md)

## 직접 체험하기

로그인 없이 시작합니다. 첫 화면의 **3분 데모 투어**에서 거래처 → 견적 → 주문 → 부분 납품 → 수금 흐름을 따라갈 수 있습니다. 최근 6개월 가상 실적, 12개 거래처, 40개 견적, 36개 주문, 55개 전표와 PDF·XLSX 예시 문서가 준비됩니다. 날짜는 데모 초기화 시점에 맞춰 생성합니다.

**수금을 직접 기록해 보세요.** 연결된 전표의 잔액과 자동 할 일이 함께 바뀝니다. 변경 사항과 생성 문서는 브라우저에 저장되며 다른 방문자와 공유되지 않습니다. 상단 **초기화**로 처음부터 다시 체험할 수 있습니다. 브라우저 저장소를 지우면 체험 기록도 사라집니다.

PC에서는 전체 업무를 체험합니다. 모바일은 개요, 직접 등록한 할 일 관리, 거래처 조회, 가이드 검색을 지원하며 견적·전표·문서 작업은 PC 이용 안내를 표시합니다.

## 주요 기능

| 업무 | 동작 |
| --- | --- |
| 거래처·CRM | 연락처, 거래 이력, 직접 등록한 할 일, 전역 검색 |
| 견적·주문 | 품목 가격표, 내부 예상 원가·마진, 견적 버전, 주문 전환 |
| 통합 장부 | 매출·매입·경비 전표, 증빙 메모, 취소·수정 이력 |
| 수금·지급 | 착수금·잔금·선입금, 전표별 결제 연결, 미결제 잔액 |
| 납품·재고 | 부분 납품·입고, 이동평균 원가, 잠정 원가 표시 |
| 문서 | 견적·거래명세서 PDF·XLSX, 내부 원가 제외, 브라우저 보관·백업 |
| 업무 가이드 | 버전 관리된 가이드 문서 검색과 관련 업무 이동 |

청구, 실제 공급, 현금 결제를 독립적으로 기록하며 차변·대변이 일치하는 분개를 생성합니다. 대시보드의 확정 매출은 VAT 포함 청구액, 예상 순이익은 실제 공급 매출에서 원가·발생 경비·입력된 세금 추정액을 차감한 값입니다. 취소·정정, 재고 부족, 중복 전표와 결제 초과에 대한 검증을 포함합니다.

## 공개 데모의 실행 범위

공개 배포는 `index.py` → `demo_cloud.py`를 실행합니다. 기존 Python 업무 엔진과 JavaScript 도메인 계산·입력 흐름을 재사용하며, 운영용 인증·PostgreSQL·비공개 파일 저장 어댑터는 실행하지 않습니다. API는 브라우저에서 받은 체험 장부에 명령을 적용해 결과를 반환합니다. 공유 서버에 방문자 장부를 저장하지 않습니다. 변경 명령 실행과 문서 해석·출력에는 네트워크가 필요합니다.

가이드는 **문서 검색 데모**이며 생성형 AI를 호출하지 않습니다. OpenAI·Claude·은행·홈택스·팝빌의 실제 연동과 비용 발생 작업은 공개 실행 경로에서 차단됩니다. 가상 문서를 업로드하면 서버 임시 디렉터리에서 읽은 후 삭제하며, 원본은 브라우저에 보관합니다. 실제 업무 자료나 개인정보는 입력하지 마세요.

## 로컬 실행

Python 3.12+와 Node.js 24+를 사용합니다.

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python index.py
```

`http://127.0.0.1:8791`에서 실행합니다. 데모에는 환경 변수나 데이터베이스가 필요하지 않습니다.

```sh
npm ci
npm test
python -m unittest discover -s tests -p 'test_*.py'
python scripts/check_release.py --git
```

기존 업무 엔진 회귀 검사와 공개 데모의 격리·결제·문서 출력·외부 호출 차단 검사를 포함합니다. 운영 PostgreSQL 통합 검사와 실제 원본 파일 검사는 해당 자원이 없는 환경에서 건너뜁니다. DOM 검사는 브라우저 시각 검사를 대체하지 않습니다.

## 배포

새 Vercel 프로젝트에 이 저장소를 연결하고 Flask 프레임워크를 선택합니다. 운영 프로젝트의 환경 변수·DB·저장소를 가져오지 않습니다. `vercel.json`의 진입점은 공개 데모이며 배포에는 테스트·로컬 장부·환경 파일을 포함하지 않습니다.

```sh
vercel link --project growth-erp-portfolio
vercel --prod
```
